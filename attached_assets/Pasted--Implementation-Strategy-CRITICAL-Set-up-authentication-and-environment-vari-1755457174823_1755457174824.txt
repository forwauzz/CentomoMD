DATABASE INTEGRATION:
Connect to existing Supabase database with these tables:
- users (id, email, oauth_provider, role, status, full_name)
- doctor_profiles (user_id, doctor_id, credentials, specialty)
- user_invitations (admin-controlled invitations)

AUTHENTICATION FLOW:
1. User chooses auth method (Google OAuth / Email+Password)
2. Authenticate through Supabase
3. Create/update user record in users table
