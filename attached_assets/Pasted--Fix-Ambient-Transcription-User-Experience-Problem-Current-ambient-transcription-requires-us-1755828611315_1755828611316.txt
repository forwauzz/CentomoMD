# Fix Ambient Transcription User Experience

## Problem
Current ambient transcription requires users to wait 30 seconds before seeing any results, causing them to stop recording prematurely. Need to change to real-time streaming experience.

## Task: Change from 30-second chunks to 3-second chunks

```typescript

  chunkDurationMs: 30000, // 30 seconds
  // ... rest of config
};
```

**To this:**
```typescript

  chunkDurationMs: 3000, // 3 seconds - CHANGED FROM 30000
  overlapMs: 500, // CHANGED FROM 2000 - shorter overlap for faster chunks
  // ... rest of config unchanged
```

## Expected Result

After these changes:
1. Users will see transcription results every 3 seconds instead of 30 seconds
2. The countdown will show "3s until processing" instead of "30s until processing"  
3. Much better user experience - feels like real-time transcription
4. Browser Whisper will process smaller chunks faster
5. Users won't abandon the feature before seeing results
